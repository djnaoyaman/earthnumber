# Earth Numberの操作イベント

2026年11月23日更新。送信先は `G-BRYWJ6L872`。

| イベント | 発火条件 | パラメータ |
|---|---|---|
| select_content | メニューや一覧で、登録済みの展示を選択したとき | content_type=exhibit、item_id=登録済み展示ID |
| content_filter | 展示一覧の学習段階・分野を変更、または分類をリセットしたとき | filter_type=level/genre/reset、filter_value=既定の分類値 |
| simulation_interact | トップページ内の各展示のボタン、スライダー、選択欄をそのページ表示で初めて操作したとき | item_id=登録済み展示ID、control_type=button/range/select |

`simulation_interact` は同じ展示で1回だけ送ります。スライダーの連続値は送らず、changeで操作の確定を扱います。単に展示へ移動したことと、展示の操作を区別します。理解度や学習完了を示すイベントではありません。

初期描画、URLからの絞込復元、戻る操作、合成イベントでは発火しません。同じ分類の再クリックも送信しません。検索入力の操作、検索語、自由入力、数値入力値は計測しません。

`interaction-events.js` をトップと展示一覧で1回ずつ読み込みます。再読込時の二重bind防止、サイトパスの限定、GA無効フラグの尊重、クエリ・ハッシュを除いたページ情報を実装しています。展示IDは `catalog-data.js` の34件を正本とします。展示を追加した場合はこの許可リストも更新してください。

## 送信範囲

計測先はこのサイトの既存GA4ストリームに限定します。新しいGoogleタグやconfigは追加していません。自由入力、検索語、回答本文、氏名、URLのクエリやハッシュを追加イベントのパラメータに含めません。自動page_view・scroll・外部リンク計測と同義のイベントも追加しません。

## 確認方法

Googleへの実送信を伴わない局所検証と、既存CIを使います。公開後の確認は変更した資産と代表ページに限定します。送信コードの確認と、GA4管理画面での受信確認は区別します。
